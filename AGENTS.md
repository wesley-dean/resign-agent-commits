# AGENTS.md

This is the concise operational map for contributors and automation.

Before consequential work, read `README.md`, `doc/resign-agent-commits-spec.md`,
`doc/decisions.md`, relevant ADRs under `doc/adr/`, `doc/threat-model.md`, and
the adopted standards under `doc/standards/`.

## Product Shape

The maintained runtime consists of `src/list_repos.bash` and
`src/resign_commits.bash`.  Discovery and signing remain separate text-composable
commands.  The signer independently rechecks repository and ref state.

## Security Invariants

- Branch names are routing signals, not proof of ownership.
- Only the contiguous single-parent suffix owned by the configured agent identity
  is eligible for rewriting.
- Human-owned and merge commits are hard boundaries.
- Present-but-invalid signatures are policy failures.
- Remote state is checked immediately before push.
- Pushes use exact force-with-lease semantics.
- `--dry-run` performs no rewrite or push.
- HTTPS tokens use GIT_ASKPASS rather than token-bearing remote URLs.
- Temporary signer state is private and removed after use.

See ADR-018 and `doc/threat-model.md`.

## Dependencies and Build

The Makefile may bootstrap only the pinned released bashdeps artifact.  bashdeps
owns `dependencies.txt`.  Do not commit `vendor/`.

bashlog is intentionally fetched but not yet integrated into runtime code.

`make build` must produce six executable artifacts and six adjacent `.sha256`
companions.  Build provenance is generated by Make, not maintained in source.

## Documentation and Validation

The normative Bash documentation standard is
`doc/standards/bash/documentation-standard.md`.

Use:

```text
make check
make test
make test-report
make deps-check
make docs
```

Bats must exercise all six executable flavors.  Local Git fixtures should be
preferred for mutation/history tests; live GitHub CI tests remain read-only.
